# Лунный календарь

Статический сайт: фаза Луны на любую дату, Луна в знаках зодиака, календарь по месяцам на 2026–2028 годы.

Демо: https://el3m3nt1212.github.io/lunar-calendar/

## Как устроено

- `build.py` считает всё заранее библиотекой [Astronomy Engine](https://github.com/cosinekitty/astronomy) и из одного шаблона собирает 37 страниц: главную и страницу на каждый месяц. У каждой страницы свой заголовок, описание, canonical-ссылка; плюс `sitemap.xml` и `robots.txt`. Это та же схема, что у SEO-сайтов «по шаблону»: добавить годы или новый тип страниц — правка одного шаблона.
- Главная — интерактивная: выбор даты, рисунок фазы, освещённость, возраст Луны, знак и время входа в следующий, ближайшие новолуние и полнолуние. Данные — `data.json`, сервер не нужен.
- Время московское (UTC+3). Знак Луны — тропический зодиак, геоцентрическая эклиптическая долгота на дату; момент входа в знак найден перебором по часу и бисекцией до секунды.
- Хостинг — GitHub Pages, бесплатно.

## Как проверено

`check.py` сверяет результат с независимой библиотекой PyEphem (другая реализация, XEphem):

- 157 моментов главных фаз — расхождение не больше 0,8 минуты;
- знак Луны в 00:00 по Москве за 1 096 дней — совпадает везде, кроме одного дня, когда Луна стояла в 0,003° от границы знака (это несколько секунд движения Луны: две библиотеки расходятся на секунды).

Вёрстка проверена на ширине телефона (375 px): горизонтальной прокрутки нет.

Код написан с Claude Code; постановка задачи, проверка расчётов и результата — моя.

## Запуск

```bash
python -m venv .venv
.venv/Scripts/python -m pip install astronomy-engine==2.1.19 ephem
.venv/Scripts/python build.py
.venv/Scripts/python check.py docs/data.json
python -m http.server 8765 --directory docs
```
